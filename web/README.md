# MiFinanzas Web

Primera base web independiente de la app Expo.

## Objetivo
- Portada pública y preparada para SEO/AdSense.
- Login web.
- Dashboard con la misma lógica funcional de la app.
- Conexión posterior al mismo Supabase de MiFinanzas.
- Animaciones cinematográficas por scroll en una segunda iteración.

## Ejecutar
```bash
cd web
npm install
npm run dev
```

Luego abre http://localhost:3000.
